APK BANANE KA TARIKA (Android Studio ki zaroorat nahi)

1. github.com par free account kholo (agar nahi hai).
2. New repository banao (naam: vocab-builder) -> "Add file" -> "Upload files".
3. Is zip ko extract karo aur andar ke SAARE files/folders (www, .github, package.json,
   capacitor.config.json) repository me upload karo. Commit karo.
   Note: ".github" folder hidden hota hai, usse bhi upload karna zaroori hai.
4. Repository me "Actions" tab kholo -> "Build APK" chalne do (3-5 minute).
5. Green tick aane par us run par click karo -> neeche "Artifacts" me
   "VocabBuilder-APK" download karo -> zip extract karo -> app-debug.apk mil jayega.
6. APK ko phone me bhejo aur install karo (Settings me "Install unknown apps" allow karna padega).

Note: Google Fonts internet se aate hain. Offline me app chalega, bas font default ho jayega.
